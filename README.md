## Microsoft To Do — Completion Date

Adds the **completion date** to tasks in the Microsoft To Do web interface. Only in the **Completed smart list**.

Microsoft To Do stores the date when a task was completed, but does not normally display it in the web UI. This userscript reads that existing local task data and displays the date next to completed tasks.

Dates are displayed in **DD.MM.YYYY** format.

### Features

- Does not make additional API requests
- cpu saving

### Privacy

All processing happens locally in the browser.

The script does not send task data anywhere and does not contact any external service.

### Requirements

A userscript manager such as:

- Tampermonkey
- Violentmonkey
- Greasemonkey
